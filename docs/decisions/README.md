# Architecture Decision Records (ADRs)

ADRs record durable owner/product/architecture decisions that future work must
preserve unless explicitly superseded.

## ADR lifecycle

Use one of: **Proposed**, **Accepted**, **Superseded**, **Rejected**.

Never edit history to make a changed decision appear as if it was always the
rule. Mark the old ADR superseded and link the new ADR.
