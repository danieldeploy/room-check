# Local spell lexicons

These Hunspell files are vendored from LibreOffice/dictionaries commit
`32b006a2c22a4ac7e8ed3f03346f7b3d85a970a4`.

- `en_GB.aff` / `en_GB.dic`: British English spell dictionary.
- `pt_PT.aff` / `pt_PT.dic`: European Portuguese spell dictionary.
- Original licence/readme files are preserved alongside the dictionaries.

They are used locally by Room Check for lexical language verification.
No runtime request to Wiktionary or another lexical web API is required.
